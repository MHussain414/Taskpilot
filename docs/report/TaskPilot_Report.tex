\begin{tphero}[title=Executive Summary]
\textbf{TaskPilot} is a production-quality \textbf{AI Project Management Chat Module}: conversational control, structured task CRUD, explainable priority scoring (0--100), live progress analytics, and team slots (max.\ 8). It runs entirely on \textbf{localhost} with Flask + SQLite and a polished dark-themed GUI. Built-in AI guarantees reliable commands; optional GPT enriches natural-language replies.

\chapter{Introduction}

\epigraph{\itshape ``The best interface is a conversation that gets work done.''}{--- TaskPilot design principle}

\section{Vision}
Modern teams need more than static todo lists. \textbf{TaskPilot} unifies \emph{natural language}, \emph{structured tasks}, and \emph{visual analytics} so users plan smarter and ship faster.

\begin{tpinfo}
\textbf{Problem:} Manual prioritization wastes time and hides deadline risk.\\
\textbf{Solution:} AI-assisted creation, automatic scoring, and real-time dashboards.\\
\textbf{Delivery:} Full web product at \url{http://127.0.0.1:5000/login/} with session auth and REST API.
\end{tpinfo}

\section{Core Objectives}
\begin{enumerate}[leftmargin=*, label=\textcolor{tpPurple}{\bfseries\arabic*.}, itemsep=0.45em]
  \item \textbf{Chat-first workflow} --- create, list, and prioritize via conversation
  \item \textbf{Transparent AI} --- every score is explainable to judges and users
  \item \textbf{Production GUI} --- not a CLI-only prototype; complete visual product
  \item \textbf{Submission-ready} --- README, \texttt{.env.example}, docs, share ZIP, this report
\end{enumerate}

\begin{tphero}[title=Scoring Model]

\normalsize\sffamily Keywords (urgent, critical), deadline proximity, status, and effort hours drive the result.
\end{tphero}
